# Personal Developer Portfolio — Muhammad Faisal

A modern, highly responsive, semantic single-page developer portfolio website designed and built to showcase full-stack web applications and applied AI/ML engineering projects. Developed as part of **Task 2** for the **Progree Remote Internship Program**.

---

## 🌟 Overview

This portfolio serves as a central visual hub detailing my technical proficiency across full-stack MERN development and machine learning technologies. Built from scratch using semantic HTML5, custom CSS layout engines (Grid & Flexbox), media queries, and vanilla JavaScript for fluid navigation.

### ✨ Key Features
- **Semantic Structure:** Leverages structural HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) for web accessibility and search engine readability.
- **Responsive Layout Engine:** Utilizes CSS Flexbox and CSS Grid to dynamically reorganize cards and skill grids across mobile, tablet, and desktop viewports.
- **Interactive Mobile Navigation:** JavaScript-powered hamburger menu drawer tailored for small screens.
- **Categorized Technical Showcase:** Highlighted competencies spanning Full-Stack MERN, Applied AI/ML libraries, and development tools.
- **Project Cards:** Deep dives into flagship applications complete with architectural details, tech stack badges, and GitHub repository links.
